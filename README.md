# Literature Radar · 个人文献雷达

**找文献、做初筛、整理进 Zotero，在一个工作台里接着做。**

搜到一百多篇文章以后，往往还有一大堆活：合并重复记录，逐篇看摘要，判断跟课题有没有关系，再把值得读的文章放进 Zotero。过几天重新打开清单，还得回想当时为什么留下这篇、那篇又为什么没选。

我做 Literature Radar，就是想把这些工作接起来。检索方案、找到的文献、AI 的建议和自己的判断，都能留在同一个课题下面，下次继续做时有据可查。

它是一款运行在 **Windows 上的生物医学文献检索与整理工具**，主要面向医学、生命科学方向的研究生和科研人员。你可以用它开始一个课题的文献调研，也可以整理已经检索出来的一批候选文献。

## 从一个熟悉的课题开始

比如，你想了解“某个分子与小胶质细胞吞噬功能有什么关系”。

先把研究目标写进去，生成检索方案后，检查分子名称、别名、物种和检索范围，再开始查找。软件会通过 PubMed、Europe PMC 的多条检索路线获取文献，合并重复记录，并保留来源。

结果出来后，可以运行语义排序和 AI 初筛，先看更值得关注的文章。每篇的推荐等级和理由都能打开查看；你可以修改判断、写备注，再把选中的文献导出成 Excel、CSV，或同步到 Zotero。

**建议第一次就拿你熟悉的课题试。** 看看已经知道的重要论文能不能找到，再检查那些被排在后面的文章。这样比换一个完全陌生的课题，更容易判断它是否适合你的工作。

## 做文献调研时，几个比较实用的地方

**想得清楚一点，再开始搜。** 研究目标可以整理成可编辑的筛选标准和检索方案。你能检查和修改检索词，调整同义词、物种和疾病范围，不用把一句话交出去之后只等结果。

**筛选过程留得下来。** AI 会给出建议等级和理由，人工判断可以覆盖 AI 建议。检索召回的候选记录会保留，低优先级文章也能回头复查。没有摘要的记录会标明情况，不能靠 AI 凭空补出正文结论。

**整理结果时少做一些重复操作。** 同一篇文章从不同来源找到后，会合并记录并保留检索来源。不同项目可以分别管理筛选标准和判断；结果能导出，也能继续整理进 Zotero，已有条目优先复用。

**找全文和管理文献放在相邻的位置。** 软件可以查找可获取的开放 PDF，找不到时会保留文献条目和处理状态。使用 Zotero 配套 Bridge 后，可以把已获取的 PDF 导入现有条目。TLDR 依据标题和摘要生成，适合初步浏览；需要精读的文章仍要打开原文。

## 下载和开始使用



1. 在 [Releases](https://github.com/nangcing2-svg/literature-radar-updates/releases) 选择正式版的 `Setup.exe`，双击安装。软件自带运行环境，不需要自己安装 Python、运行命令或配置开发环境。
2. 第一次启动需要联网领取 **15 天试用**。
3. 在设置里配置你要使用的服务。AI 功能需要自己的 DeepSeek API Key；要同步 Zotero，再配置 Zotero。其余可选服务可以以后按需补充。

日常使用时，从桌面或开始菜单打开 Literature Radar 即可。更新程序时，下载同通道的新版安装 EXE，等待科研任务结束并关闭软件后覆盖安装。

## 使用前值得知道的几件事

- **AI 初筛需要复核。** 检索词、数据库收录和元数据质量都可能影响结果。发现了重要文章，或怀疑有漏检时，仍应回到数据库、参考文献和原文核查。
- **项目资料保存在本机。** 检索和 AI 分析需要访问相应服务；使用 AI 时，待分析的标题、摘要及相关筛选要求会发送给你配置的服务商。
- **全文获取以实际可访问的开放来源为准。** 下载不到 PDF 不会让已经找到的文献条目消失。
- **文献记录可以导出。** 保留定期备份的习惯，尤其是在升级程序或换电脑之前。

如果你已经有一套顺手的检索方法，可以先挑其中最费时间的一步来试，比如初筛一批摘要，或把结果整理进 Zotero。不必一次改变自己的全部工作方式。
